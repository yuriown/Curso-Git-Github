# 🔍 Rastreamento e Histórico

## 📚 Resumo das Aulas e Conceitos

### 1. Rastreando com Git Log
* **Para que serve o `git log`?**  
  Exibe o histórico completo dos commits realizados no repositório, indicando o autor, data, hash e mensagem de cada alteração.
* **Comandos e variações úteis:**
  * `git log`: Exibe o histórico completo detalhado.
  * `git log --oneline`: Exibe cada commit em apenas uma linha (hash reduzido + mensagem).
  * `git log -p`: Mostra o histórico acompanhado das alterações linha a linha (diff).
  * `git log --graph`: Exibe uma representação gráfica em modo texto das ramificações de branches.
